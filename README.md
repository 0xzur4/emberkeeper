Emberkeeper is a top-down arena survival game: keep the last lantern lit against waves of shadows. Move with WASD or arrows, aim with the mouse, hold click to shoot embers, gather the fallen ones, and choose a blessing between waves. Shades chase, skitters dart, brutes endure, and a boss rules every fifth wave.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
